## Выполнение заданий

### Задача 2.1.4. Дроби

**Условие.** Сделать дробь неизменяемой и обрабатывать отрицательные значения. Знаменатель должен быть положительным.

**Алгоритм решения.** Хранить числитель и знаменатель в неизменяемых полях. При отрицательном знаменателе перенести знак в числитель. При нуле запросить новый знаменатель.

**Результат выполнения.** `3/(-5) → -3/5`.

### Задача 2.1.10. Дороги

**Условие.** Разрешить создавать города с готовыми дорогами, добавлять и удалять дороги. Для пары городов разрешить одну дорогу в каждом направлении.

**Алгоритм решения.** Создавать город с готовыми дорогами, добавлять и удалять дороги. Хранить соседей и стоимости в двух массивах. Перед добавлением проверять, есть ли дорога к этому объекту города.

**Результат выполнения.** `A -> [B:5]`. Повторное добавление выводит сообщение об ошибке. После удаления — `A -> []`.

### Задача 2.2.5. Маршрут

**Условие.** Найти путь между двумя городами и вернуть его массивом. Разрешить менять начало и конец за O(1). Показать маршрут из F в D.

**Алгоритм решения.** Хранить два города, которые можно менять за O(1). Перебирать соседей в порядке их добавления в очередь. Запоминать, из какого города пришли в каждый следующий. После нахождения конца собрать путь в массив. Если конец недостижим, вернуть пустой массив.

**Результат выполнения.** На карте из задачи 1.3.3 получается `F -> B -> A -> D`. Путь выбирается по количеству дорог.

### Задача 2.3.1. Запретная дробь

**Условие.** Запретить создание подкласса, который мог бы сделать дробь изменяемой.

**Алгоритм решения.** Объявить класс `Fraction` как `final`, чтобы наследование было запрещено.

**Результат выполнения.** `Fraction` создаётся через конструктор. Его поля доступны только внутри класса.

### Задача 2.3.5. Трёхмерная точка

**Условие.** Создать подвид точки с координатами X, Y и Z.

**Алгоритм решения.** Унаследовать X и Y от `Point`, добавить Z и переопределить строковое представление.

**Результат выполнения.** Координаты 4, 2, 5 выводятся как `{4,2,5}`.

### Задача 2.4.2. Дробь это число

**Условие.** Сделать дробь подтипом стандартного класса `Number`.

**Алгоритм решения.** Унаследовать `Fraction` от `Number` и реализовать четыре числовых преобразования.

**Результат выполнения.** `-3/5` как `double` даёт `-0.6`.

### Задача 2.5.1. Сложение

**Условие.** Сложить числа разных типов и вернуть вещественный результат. Посчитать три суммы из PDF.

**Алгоритм решения.** Принять массив значений `Number`, вызвать `doubleValue()` у каждого числа и сложить результаты.

**Результат выполнения.** `2 + 3/5 + 2.3 = 4.9`, `3.6 + 49/12 + 3 + 3/2 ≈ 12.183333333333334`, `1/3 + 1 ≈ 1.3333333333333333`.

### Задача 2.6.5. Сравнение городов

**Условие.** Сравнить города по набору дорог. Обычный город должен сравниваться с городом, добавляющим обратные дороги.

**Алгоритм решения.** Сравнивать наборы дорог по объектам городов назначения и стоимости. Порядок добавления и название исходного города не участвуют в сравнении. `TwoWayCity` добавляет обратную дорогу и использует тот же `equals()`.

**Результат выполнения.** Для `A -> [C:5]` и `B -> [C:5]` сравнение даёт `true` в обе стороны. У C появляется обратная дорога `C -> [B:5]`.

### Задача 2.7.1. Навести порядок

**Условие.** Распределить классы по пакетам вида `ru.фамилия.назначение`.

**Алгоритм решения.** Сгруппировать классы по назначению в пакетах с фамилией.

**Результат выполнения.** `ru.gubaidulin.cities`, `ru.gubaidulin.geometry`, `ru.gubaidulin.numbers`, `ru.gubaidulin.main`.

### Задача 2.7.2. Главный метод

**Условие.** Расположить точку входа и метод сложения в пакете `ru.gubaidulin.main`. Показать работу метода.

**Алгоритм решения.** Разместить точку входа и класс с методом сложения в пакете `ru.gubaidulin.main`.

**Результат выполнения.** `Main` запускает меню, `NumberOperations.sum(1, new Fraction(1, 2))` возвращает `1.5`.

### Задача 2.7.3. Возведение в степень

**Условие.** Вычислить степень по двум строкам из аргументов запуска. Использовать короткие имена `parseInt` и `pow`.

**Алгоритм решения.** Прочитать два аргумента запуска. В методе использовать статические импорты `parseInt` и `pow`.

**Результат выполнения.** Для аргументов `2 -3` получается `0.125`.

### Задача 2.8.4. Клонирование точки

**Условие.** Переопределить `clone()`, чтобы новый объект точки имел те же координаты.

**Алгоритм решения.** Реализовать `Cloneable` и переопределить `clone()`, чтобы `super.clone()` скопировал поля.

**Результат выполнения.** Оригинал и копия выводятся как `{2,5}`. Координаты совпадают, ссылки различаются.

## Организация ввода и проверка ошибок

Программа показывает пример выбранной задачи. Для ручного ввода выберите `1`, для возврата в меню — `0`. Пункт `0` в главном меню завершает работу.

Для чтения используется `Scanner`. Программа проверяет числовые диапазоны, непустые названия, ненулевой знаменатель и наличие повторных дорог. При ошибке выводит подсказку и повторяет запрос.

## Запуск программы

Требуются JDK 21 или новее и Maven. В IntelliJ IDEA выберите конфигурацию **«Лаба 3»**. Для запуска из терминала в корне проекта выполните:

```bash
mvn compile
java -cp target/classes ru.gubaidulin.main.Main
```

Для задачи о степени можно передать два аргумента:

```bash
java -cp target/classes ru.gubaidulin.main.Main 2 -3
```
