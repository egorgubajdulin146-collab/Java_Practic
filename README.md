## Выполнение заданий

### Задача 1.2. Человек

**Условие.** Создать сущность «Человек» с именем в виде строки и ростом в виде целого числа. Предусмотреть строковое представление вида «Имя, рост: значение». Создать Клеопатру с ростом 152, Пушкина с ростом 167 и Владимира с ростом 189.

**Алгоритм решения.** В классе `SimplePerson` объявлены поля `name` и `height`. Конструктор проверяет, что имя заполнено и не содержит управляющих символов, а рост положительный. После проверки данные сохраняются в полях объекта. Метод `toString()` формирует строку с именем и ростом.

**Результат выполнения:**

```text
Клеопатра, рост: 152
Пушкин, рост: 167
Владимир, рост: 189
```

### Задача 1.3. Имена

**Условие.** Создать сущность «Имя» с фамилией, личным именем и отчеством. Отдельные части имени могут отсутствовать и не должны участвовать в строковом представлении. Создать имена «Клеопатра», «Пушкин Александр Сергеевич» и «Маяковский Владимир».

**Алгоритм решения.** В классе `FullName` каждая часть имени хранится в отдельном поле. Метод `normalize()` заменяет отсутствующее значение `null` пустой строкой, проверяет символы и удаляет пробелы по краям. Конструктор требует заполнения хотя бы одной части имени. В `toString()` непустые части последовательно соединяются пробелами.

**Результат выполнения:**

```text
Клеопатра
Пушкин Александр Сергеевич
Маяковский Владимир
```

### Задача 2.2. Человек с именем

**Условие.** Объединить сущности «Человек» и «Имя» так, чтобы имя человека задавалось объектом `FullName`. Создать людей с именами из предыдущей задачи и ростом 152, 167 и 189 соответственно.

**Алгоритм решения.** В классе `Person` объявлены поле `name` типа `FullName` и целочисленное поле `height`. Конструктор принимает готовый объект имени и рост, проверяет их и сохраняет в полях. При формировании строки используется метод `toString()` объекта `FullName`, после чего добавляется рост.

**Результат выполнения:**

```text
Клеопатра, рост: 152
Пушкин Александр Сергеевич, рост: 167
Маяковский Владимир, рост: 189
```

### Задача 3.3. Города

**Условие.** Создать сущность «Город» с названием и набором путей в другие города. Каждый путь содержит город назначения и стоимость поездки. Воспроизвести схему городов и путей из задания и вывести для каждого города список соседей со стоимостью поездки.

**Алгоритм решения.** В классе `City` используются название `name` и два массива: `destinations` для городов назначения и `costs` для стоимостей. Элементы с одинаковым индексом описывают один путь. Метод `hasRoute()` перебирает массив соседей и проверяет наличие прямого пути.

Метод `addRoute()` проверяет город назначения, отсутствие повторного пути и неотрицательную стоимость. Для добавления создаются массивы на один элемент длиннее. Старые данные копируются циклом, а новый путь записывается в конец. Пути направленные: обратное направление добавляется отдельно.

Метод `toString()` формирует строку с названием текущего города и парами «название соседа:стоимость».

**Результат выполнения:**

```text
A -> [B:5, F:1, D:6]
B -> [A:5, C:3]
C -> [B:3, D:4]
D -> [A:6, C:4, E:2]
E -> [F:2]
F -> [B:1, E:2]
```

### Задача 4.8. Создаём города

**Условие.** Предусмотреть создание города только по названию, а также по названию и набору связанных городов со стоимостями путей.

**Алгоритм решения.** В классе `City` реализованы два конструктора. Конструктор `City(String name)` вызывает второй конструктор и передаёт ему название и два пустых массива. Конструктор `City(String name, City[] destinations, int[] costs)` проверяет название, наличие массивов и совпадение их длины. Затем добавляет пути через `addRoute()`.

Данные переданных массивов копируются во внутренние массивы города. Замена элементов исходных массивов после создания объекта не изменяет сохранённые пути.

**Результат выполнения.** Города A–E создаются только по названию. Город F создаётся сразу с массивом соседей B и E и массивом стоимостей 1 и 2. После добавления остальных путей получается схема, приведённая в задаче 3.3.

### Задача 5.5. Дроби

**Условие.** Создать сущность «Дробь» с целыми числителем и знаменателем. Реализовать строковое представление «числитель/знаменатель», сложение, вычитание, умножение и деление с другой дробью и целым числом. Результатом каждой операции должна быть новая дробь. Вычислить выражение `f1.sum(f2).div(f3).minus(5)`.

**Алгоритм решения.** В классе `Fraction` числитель и знаменатель хранятся в закрытых полях типа `int`. Конструктор запрещает нулевой знаменатель и при необходимости переносит знак в числитель. Метод `gcd()` находит наибольший общий делитель алгоритмом Евклида. Числитель и знаменатель делятся на НОД, поэтому дробь сохраняется в сокращённом виде с положительным знаменателем.

Для дробей `a/b` и `c/d` используются следующие формулы:

| Операция | Формула результата |
| --- | --- |
| Сложение | `(a*d + c*b) / (b*d)` |
| Вычитание | `(a*d - c*b) / (b*d)` |
| Умножение | `(a*c) / (b*d)` |
| Деление | `(a*d) / (b*c)` |

Промежуточные вычисления выполняются в `long`. После сокращения конструктор проверяет, помещаются ли числитель и знаменатель в `int`. При выходе за допустимые границы выводится сообщение об ошибке. Перед делением дополнительно проверяется ненулевой числитель дроби-делителя.

Для операций с целым числом оно преобразуется в дробь со знаменателем 1. Затем вызывается соответствующий метод для двух дробей. Каждая операция возвращает новый объект, поэтому исходные дроби сохраняют свои значения.

**Результат выполнения** для `f1 = 1/3`, `f2 = 2/3`, `f3 = 3/4` и целого числа 2:

```text
1/3 + 2/3 = 1/1
1/3 - 2/3 = -1/3
1/3 * 2/3 = 2/9
1/3 / 2/3 = 1/2
1/3 + 2 = 7/3
1/3 - 2 = -5/3
1/3 * 2 = 2/3
1/3 / 2 = 1/6
f1.sum(f2).div(f3).minus(5) = -11/3
Исходные дроби: f1 = 1/3, f2 = 2/3, f3 = 3/4
```

## Организация ввода и проверка ошибок

После выбора задания пользователь выбирает режим: готовый пример или ввод собственных данных. После выполнения задания программа возвращается в главное меню. Для завершения работы используется пункт 0.

| Проверяемые данные | Условие допустимости |
| --- | --- |
| Пункт меню | Целое число от 0 до 6 |
| Режим работы | Целое число 1 или 2 |
| Количество людей, имён или городов | Целое число от 1 до 100 |
| Имя человека и название города | Непустой текст без управляющих символов |
| Полное имя | Заполнена хотя бы одна часть имени |
| Рост | Положительное число в пределах `int` |
| Названия городов при ручном вводе | Уникальные без учёта регистра |
| Путь | Существующий другой город, направление ещё не добавлено |
| Стоимость пути | Целое число от 0 до `Integer.MAX_VALUE` |
| Знаменатель дроби | Ненулевое целое число; после сокращения положительный знаменатель помещается в `int` |
| Делитель | Ненулевое число или ненулевая дробь |
| Результат операции с дробями | Числитель и знаменатель после сокращения помещаются в `int` |

Неправильный ввод сопровождается сообщением и повторным запросом. Ошибки арифметических операций выводятся отдельно, после чего программа продолжает работу. При завершении потока ввода программа корректно заканчивает выполнение.
