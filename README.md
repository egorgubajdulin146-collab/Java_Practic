# Лабораторные работы по Java

Учебный проект студента Губайдулина Егора, группа ИТ-18, 2 курс.

**Дисциплина:** Языки программирования Java  
**Вариант:** 2

## Структура репозитория

Ветка `main` содержит общее описание проекта.

Для каждой лабораторной работы создаётся отдельная ветка:

- `lab1` — код и отчёт лабораторной работы №1;
- `lab2` — код и отчёт лабораторной работы №2;
- следующие работы будут находиться в ветках `lab3`, `lab4` и так далее.

В каждой ветке находится только одна лабораторная работа, один класс `Main` и отчёт в формате Markdown.
