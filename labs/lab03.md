# Задание 1. Инкапсуляция

## Задача 4. Дроби

### Текст задачи

Сделать дробь неизменяемой и обрабатывать отрицательные значения. Знаменатель должен быть положительным.

### Алгоритм решения

Хранить числитель и знаменатель в неизменяемых полях. При отрицательном знаменателе перенести знак в числитель. При нуле запросить новый знаменатель.

### Результат

`3/(-5) → -3/5`.

## Задача 10. Дороги

### Текст задачи

Разрешить создавать города с готовыми дорогами, добавлять и удалять дороги. Для пары городов разрешить одну дорогу в каждом направлении.

### Алгоритм решения

Создавать город с готовыми дорогами, добавлять и удалять дороги. Хранить соседей и стоимости в двух массивах. Перед добавлением проверять, есть ли дорога к этому объекту города.

### Результат

`A -> [B:5]`. Повторное добавление выводит сообщение об ошибке. После удаления — `A -> []`.

# Задание 2. Разработка структур данных

## Задача 5. Маршрут

### Текст задачи

Найти путь между двумя городами и вернуть его массивом. Разрешить менять начало и конец за O(1). Показать маршрут из F в D.

### Алгоритм решения

Хранить два города, которые можно менять за O(1). Перебирать соседей в порядке их добавления в очередь. Запоминать, из какого города пришли в каждый следующий. После нахождения конца собрать путь в массив. Если конец недостижим, вернуть пустой массив.

### Результат

На карте из задачи 1.3.3 получается `F -> B -> A -> D`. Путь выбирается по количеству дорог.

# Задание 6. Полиморфное сравнение

## Задача 5. Сравнение городов

### Текст задачи

Сравнить города по набору дорог. Обычный город должен сравниваться с городом, добавляющим обратные дороги.

### Алгоритм решения

Сравнивать наборы дорог по объектам городов назначения и стоимости. Порядок добавления и название исходного города не участвуют в сравнении. `TwoWayCity` добавляет обратную дорогу и использует тот же `equals()`.

### Результат

Для `A -> [C:5]` и `B -> [C:5]` сравнение даёт `true` в обе стороны. У C появляется обратная дорога `C -> [B:5]`.

# Пользовательский ввод

Программа показывает пример выбранной задачи. Для ручного ввода выберите `1`, для возврата в меню — `0`. Пункт `0` в главном меню завершает работу.

Для чтения используется `Scanner`. Программа проверяет числовые диапазоны, непустые названия, ненулевой знаменатель и наличие повторных дорог. При ошибке выводит подсказку и повторяет запрос.

# Запуск программы

Требуются JDK 21 или новее и Maven. В IntelliJ IDEA выберите конфигурацию **«Лаба 3»**. Для запуска из терминала в корне проекта выполните:

```bash
mvn compile
java -cp target/classes ru.gubaidulin.main.Main
```

Для задачи о степени можно передать два аргумента:

```bash
java -cp target/classes ru.gubaidulin.main.Main 2 -3
```
