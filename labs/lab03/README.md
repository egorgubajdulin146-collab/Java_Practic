## Запуск на Java 21

Выполните из корня проекта:

```sh
mkdir -p out/lab03
javac --release 21 -encoding UTF-8 -d out/lab03 $(find src/main/java/ru/gubaidulin -name '*.java')
java -cp out/lab03 ru.gubaidulin.main.Main
```

Меню запускает готовые примеры. В пунктах с ручным вводом выберите `1` для своих данных или `0` для возврата в меню. Для выхода выберите `0` в главном меню. В IntelliJ IDEA выберите JDK 21 и запустите `ru.gubaidulin.main.Main`.

Для задачи 2.7.3 передайте два целочисленных аргумента:

```sh
java -cp out/lab03 ru.gubaidulin.main.Main 2 -3
```

Результат — `0.125`.

## Короткий текст для защиты

У меня вариант 2. Я разделил классы по пакетам и сделал консольное меню с готовыми примерами и ручным вводом. Дробь хранит два числа. Знак всегда остаётся в числителе, а поля после создания не меняются. Дробь наследуется от Number, поэтому метод сложения работает с целыми, вещественными числами и дробями. Для поиска маршрута перебираю соседей по очереди. Так первым находится путь с наименьшим количеством дорог. Города сравниваю по их дорогам. Трёхмерная точка берёт две координаты у обычной точки и добавляет третью. При клонировании создаётся отдельный объект с теми же координатами. В задаче со степенью два числа можно передать при запуске программы.
