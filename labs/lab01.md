# Задание 1. Методы

## Задача 6. Большая буква

### Текст задачи

Реализовать метод `public boolean isUpperCase(char x)`, который принимает символ `x` и возвращает `true`, если он является заглавной латинской буквой в диапазоне от `A` до `Z`. В остальных случаях метод должен возвращать `false`.

### Алгоритм решения

Сравнить код принятого символа с кодами символов `A` и `Z`. Если символ одновременно не меньше `A` и не больше `Z`, вернуть `true`, иначе вернуть `false`.

## Задача 7. Диапазон

### Текст задачи

Реализовать метод `public boolean isInRange(int a, int b, int num)`, который проверяет, входит ли число `num` в диапазон между числами `a` и `b`, включая его границы. Заранее неизвестно, какая из границ больше.

### Алгоритм решения

Проверить два возможных порядка границ. Число входит в диапазон, если оно находится между `a` и `b` либо между `b` и `a` включительно.

## Задача 8. Делитель

### Текст задачи

Реализовать метод `public boolean isDivisor(int a, int b)`, который возвращает `true`, если одно из принятых чисел делит другое без остатка.

### Алгоритм решения

Проверить остаток от деления `b` на `a`, а затем остаток от деления `a` на `b`. Перед каждой операцией убедиться, что делитель не равен нулю. Если хотя бы один остаток равен нулю, вернуть `true`.

## Задача 9. Равенство

### Текст задачи

Реализовать метод `public boolean isEqual(int a, int b, int c)`, который возвращает `true`, если все три числа равны.

### Алгоритм решения

Сравнить первое число со вторым и второе с третьим. Если оба сравнения дают истину, вернуть `true`, иначе вернуть `false`.

## Задача 10. Многократный вызов

### Текст задачи

Реализовать метод `public int lastNumSum(int a, int b)`, который складывает последние цифры двух чисел. С помощью последовательных вызовов метода выполнить сложение пяти чисел и вывести итоговый результат.

### Алгоритм решения

Получить последние цифры чисел с помощью остатка от деления на 10 и сложить их. Результат первого вызова передавать как первый аргумент следующего вызова, пока не будут обработаны все пять чисел.

# Задание 2. Условия

## Задача 6. Тройная сумма

### Текст задачи

Реализовать метод `public boolean sum3(int x, int y, int z)`, который возвращает `true`, если сумма любых двух из трёх чисел равна третьему числу.

### Алгоритм решения

Последовательно проверить три выражения: `x + y == z`, `x + z == y` и `y + z == x`. Если хотя бы одно условие выполняется, вернуть `true`.

## Задача 7. Двойная сумма

### Текст задачи

Реализовать метод `public int sum2(int x, int y)`, который возвращает сумму чисел `x` и `y`. Если сумма находится в диапазоне от 10 до 19 включительно, метод должен вернуть 20.

### Алгоритм решения

Вычислить сумму двух чисел. Проверить, попадает ли она в диапазон от 10 до 19. Если попадает, вернуть 20, иначе вернуть вычисленную сумму.

## Задача 8. Возраст

### Текст задачи

Реализовать метод `public String age(int x)`, который возвращает возраст с правильным словом: «год», «года» или «лет». Для чисел, оканчивающихся на 11–14, используется слово «лет».

### Алгоритм решения

Получить последние две цифры числа. Если они находятся в диапазоне от 11 до 14, добавить слово «лет». В остальных случаях проверить последнюю цифру: для 1 использовать «год», для 2–4 — «года», для остальных значений — «лет».

## Задача 9. День недели

### Текст задачи

Реализовать метод `public String day(int x)`, который по номеру от 1 до 7 возвращает название дня недели. Числу 1 соответствует понедельник, числу 7 — воскресенье. Для другого числа вернуть строку «это не день недели». Использовать `switch`.

### Алгоритм решения

Передать число в конструкцию `switch`. В каждом варианте от 1 до 7 вернуть соответствующее название дня. В блоке `default` вернуть сообщение об ошибочном значении.

## Задача 10. Вывод дней недели

### Текст задачи

Реализовать метод `public void printDays(String x)`, который выводит указанный день недели и все следующие дни до воскресенья. Если переданная строка не является названием дня недели, вывести сообщение «это не день недели». Использовать `switch`.

### Алгоритм решения

Использовать `switch` без `break` между правильными названиями дней. Выполнение начнётся с выбранного дня и продолжится до воскресенья. После воскресенья поставить `break`. Для неправильной строки использовать `default`.

# Задание 3. Циклы

## Задача 6. Одинаковость

### Текст задачи

Реализовать метод `public boolean equalNum(int x)`, который возвращает `true`, если все цифры числа одинаковые, и `false` в остальных случаях.

### Алгоритм решения

Взять последнюю цифру числа как образец. В цикле сравнивать с ней каждую следующую цифру, полученную через остаток от деления на 10. После проверки удалять последнюю цифру целочисленным делением на 10. При обнаружении отличающейся цифры вернуть `false`.

## Задача 7. Квадрат

### Текст задачи

Реализовать метод `public void square(int x)`, который выводит квадрат из символов `*` размером `x` строк на `x` символов.

### Алгоритм решения

Использовать два вложенных цикла. Внешний цикл отвечает за строки, внутренний выводит `x` звёздочек в каждой строке. После завершения внутреннего цикла перейти на новую строку.

## Задача 8. Левый треугольник

### Текст задачи

Реализовать метод `public void leftTriangle(int x)`, который выводит треугольник высотой `x`. В первой строке должна быть одна звёздочка, а в каждой следующей — на одну больше.

### Алгоритм решения

Внешним циклом перебирать номера строк от 1 до `x`. Внутренним циклом выводить столько звёздочек, сколько соответствует номеру текущей строки.

## Задача 9. Правый треугольник

### Текст задачи

Реализовать метод `public void rightTriangle(int x)`, который выводит треугольник высотой `x`, выровненный по правому краю.

### Алгоритм решения

Для каждой строки сначала вывести `x - номер строки` пробелов, затем вывести количество звёздочек, равное номеру строки. После этого перейти на новую строку.

## Задача 10. Угадайка

### Текст задачи

Реализовать метод `public void guessGame()`, который загадывает случайное число от 0 до 9 и предлагает пользователю угадать его. Игра продолжается до правильного ответа, после чего выводится количество попыток.

### Алгоритм решения

Создать случайное число от 0 до 9. В бесконечном цикле считывать число пользователя и проверять правильность ввода. Увеличивать счётчик допустимых попыток. Если число совпало с загаданным, вывести результат и завершить цикл, иначе предложить повторить попытку.

# Задание 4. Массивы

## Задача 6. Реверс

### Текст задачи

Реализовать метод `public void reverse(int[] arr)`, который изменяет переданный массив, располагая его элементы в обратном порядке.

### Алгоритм решения

Пройти до середины массива. На каждом шаге поменять местами текущий элемент с симметричным элементом от конца массива, используя временную переменную.

## Задача 7. Возвратный реверс

### Текст задачи

Реализовать метод `public int[] reverseBack(int[] arr)`, который возвращает новый массив с элементами исходного массива в обратном порядке. Исходный массив изменяться не должен.

### Алгоритм решения

Создать новый массив такой же длины. Последовательно записать в него элементы исходного массива, начиная с последнего и заканчивая первым. Вернуть новый массив.

## Задача 8. Объединение

### Текст задачи

Реализовать метод `public int[] concat(int[] arr1, int[] arr2)`, который возвращает новый массив. Сначала в нём должны находиться элементы первого массива, затем элементы второго.

### Алгоритм решения

Создать массив, длина которого равна сумме длин двух исходных массивов. Первым циклом скопировать элементы первого массива. Вторым циклом записать элементы второго массива, начиная с позиции, равной длине первого массива.

## Задача 9. Все вхождения

### Текст задачи

Реализовать метод `public int[] findAll(int[] arr, int x)`, который возвращает массив индексов всех вхождений числа `x` в массив `arr`.

### Алгоритм решения

Первым циклом посчитать количество совпадений, чтобы определить размер результирующего массива. Создать массив нужной длины. Вторым циклом найти совпадения и записать их индексы в новый массив.

## Задача 10. Удалить негатив

### Текст задачи

Реализовать метод `public int[] deleteNegative(int[] arr)`, который возвращает новый массив без отрицательных элементов исходного массива.

### Алгоритм решения

Первым циклом посчитать количество неотрицательных элементов. Создать массив найденного размера. Вторым циклом перенести в него все элементы, которые больше или равны нулю.
